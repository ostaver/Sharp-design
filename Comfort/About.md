# Comfort

A warm, tactile design language built on soft modernism with a buttery-smooth feel. It produces a theme-aware site with a custom scroll sidebar and custom theme-change animation, with zero binary assets — built from pure text files. The name "Comfort" refers to the design language's foundational concept and will not influence the skill nor the output in any way.

> The instructions the AI follows live in **`SKILL.md`**. This file explains what the skill is, when it triggers, and how to use it.

---

## What it produces

- A complete theme-aware site with light/dark modes and a custom theme-change animation.
- A custom scroll sidebar for navigation.
- Warm, tactile, crafty aesthetic with soft modernist sensibilities.

## How to use it

1. **Use plan mode.** This skill uses frameworks and benefits from a structured approach.
2. **Provide context.** Share the desired brand voice, pages, and content requirements.
3. **Confirm creative choices.** The AI will state the chosen palette, typography, and layout.
4. **Review.** Check theme toggle, scroll sidebar behavior, and responsive layout.

## Requirements

- **Node.js** — to run the build tooling.
- **npm** — for dependency management.
- No specific runtime beyond a modern browser for the built output.

## Tech stack

- **HTML** — semantic markup.
- **CSS** — custom properties, theme system.
- **JavaScript** — interactive behaviors, animations.
- **Astro.js** — static site generation framework.
- **Anime.js** — animation library for smooth transitions.
- **Vite** — build tooling and dev server.
- **External CDNs:** Google Fonts, Lucide Icons.

## Notable characteristics

- **Warm & tactile.** Crafty, buttery-smooth aesthetic with soft modernism.
- **Theme-aware.** Light/Dark theme with a custom theme-change animation.
- **Custom scroll sidebar.** A unique navigation sidebar tied to scroll position.
- **Every build must vary.** Palette, typography, layout, and copy so no two Comfort sites look like clones.
